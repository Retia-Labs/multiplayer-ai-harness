# Shared control on a stable execution host

Early access supports collaborative agent tasks started through this product, with ordered and attributed participant input and separately delegated approval rights. A responsibility handoff changes the responsible teammate while retaining the execution host and shared context; closing a browser does not terminate work if that host remains online.

We choose this boundary because the researched provider interfaces offer controls for product-started sessions, while arbitrary adoption of active native editor sessions and migration of processes, workspaces, and credentials would require separate integration and recovery guarantees. Automatic execution migration and native-session adoption are deferred so the first release can validate everyday shared supervision. The founder accepted this scope on 2026-09-05; provider selection and detailed recovery semantics remain open.
