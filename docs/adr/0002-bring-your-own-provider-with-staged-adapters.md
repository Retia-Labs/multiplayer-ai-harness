# Bring your own provider with staged adapters

The product uses customers' own supported provider authentication, through eligible subscriptions or API access, and launches first with Codex. Claude Code and Cursor follow in quick succession through separately validated integrations. The founder accepted this direction on 2026-09-05 to reach pilots promptly while retaining a multi-provider product direction.

Adapters must expose actual control and authentication capabilities rather than imply identical behavior across providers. Subscription login does not imply credential pooling or permission for arbitrary teammates to consume one person's entitlement; the supported collaboration and billing arrangement must be established for each adapter. Provider usage billing stays in the customer's provider relationship; pricing for this product's collaboration service remains open.
