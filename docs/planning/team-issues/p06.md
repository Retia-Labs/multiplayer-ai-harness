## What to build

From an installed app, configure a supported Codex account, select an authorized repository, and run a useful solo feature task with encrypted activity and changes. Replace the noninteractive-only integration with the validated interactive contract.

Type: **AFK**. Suggested work lane: **Runtime/providers**. Parent user stories: 1, 6, 7, 8, 18, 35, 44.

## Acceptance criteria

- [ ] A real provider task executes on the displayed host and workspace, produces file changes, and streams meaningful state through the encrypted task path.
- [ ] Credentials remain in the provider/host relationship and out of shared descriptors, task content, telemetry and logs; account/version/usage-limit failures are actionable.
- [ ] Workspace restrictions and actual provider execution capabilities are enforced locally and shown accurately. Remote clients cannot silently increase privileges.
- [ ] Preserve product task identifiers separately from provider session/turn identifiers. Solo task start does not require another teammate to be online or invited.
