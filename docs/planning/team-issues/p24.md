## Acceptance criteria

- [ ] On both advertised execution platforms, two users complete encrypted join/catch-up, real correction, bounded delegated approval, diff review, help/handoff, private links and background/quit behavior.
- [ ] Exercise unauthorized endpoints, malicious relay/replay, stale grants, revocation, clean-device recovery, runtime/network interruption and supported resume. Record provider/auth/version support.
- [ ] Complete independent review of implemented privacy and control; inspect live/backup stores, logs, telemetry, notifications and diagnostics for canary plaintext. Claims accurately reflect reviewed scope.
- [ ] Confirm usable installed distribution, upgrade/recovery, onboarding/support, documented metadata/retention and service restore. A failed core technical requirement blocks external release and names a concrete remedy, not an interview prerequisite.
