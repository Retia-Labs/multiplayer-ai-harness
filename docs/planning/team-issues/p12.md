## What to build

Participants inspect the real diff after a teammate correction, record the task outcome, and transfer responsibility to an existing project member with an encrypted note.

Type: **AFK**. Suggested work lane: **Desktop/product**. Parent user stories: 18, 19, 20.

## Acceptance criteria

- [ ] The complete scenario shows an original assumption, confirmed teammate correction, resulting file change and navigable supporting task history.
- [ ] Handoff changes responsibility only, preserves shared context and clearly displays the unchanged host/workspace/provider usage owner.
- [ ] The recipient must already have project access. Responsibility does not silently grant approval rights or transfer provider credentials.
- [ ] Record open/completed/cancelled task outcome independently from individual turn status. Reuse the existing diff experience rather than adding a full editor or Git replacement.
