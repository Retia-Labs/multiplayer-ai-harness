## What to build

Alice starts a real task and Bob joins, sends an explicit agent correction and optionally interrupts. Deliver these actions through authenticated encrypted control with provider-confirmed outcomes.

Type: **AFK**. Suggested work lane: **Runtime/providers**. Parent user stories: 10, 11, 12, 13, 17.

## Acceptance criteria

- [ ] Near-simultaneous inputs retain actor attribution, stable host acceptance order, unique IDs and queued/delivered/rejected outcomes. A visible message alone is not delivery.
- [ ] Retries do not redeliver an accepted command; a changed turn rejects stale instructions instead of silently redirecting another turn.
- [ ] Interrupt shows requested/stopping until runtime/provider acknowledgment; test during tool execution and host disconnection without claiming completed side effects are undone.
- [ ] Host checks current verified collaborator authority and target task/turn. A human help message is never automatically converted into agent input.
