## What to build

A teammate opens an unfamiliar running task and sees enough verified context to contribute without reading its whole transcript. Build deterministic projections first on an authorized endpoint.

Type: **AFK**. Suggested work lane: **Desktop/product**. Parent user stories: 9, 18, 37, 38.

## Acceptance criteria

- [ ] Show objective, responsible teammate, execution host/provider, current plan/status, recent changes, recorded decisions and current blocker/pending approvals.
- [ ] Each decision and summary item links to supporting task events or saved artifacts. Distinguish explicitly recorded decisions from inference; do not invent human approval.
- [ ] Display freshness and disconnected/unknown state. A late join and reconnect produce the same catch-up state as continuous observation.
- [ ] No server-side plaintext projection is introduced. Generated summaries are optional, do not block completion, and if present run under an authorized customer provider relationship.
