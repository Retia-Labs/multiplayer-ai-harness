## What to build

Produce trustworthy macOS/Windows distribution artifacts and verify upgrade/reinstall/rollback behavior without stranding runtime state, encrypted history or credentials. Human work covers signing accounts/credentials and installed-build review.

Type: **HITL**. Suggested work lane: **Desktop/product**. Parent user stories: 1, 2, 7, 21, 22, 36.

## Acceptance criteria

- [ ] Provision and protect required signing/notarization credentials; produce reproducible artifacts and validate clean-machine install without a developer shell.
- [ ] Load trusted packaged application code, isolate/sandbox renderers as appropriate and narrowly validate privileged IPC; the production desktop must not rely on arbitrary remote renderer privileges.
- [ ] Test upgrade compatibility for runtime/provider versions, encrypted storage and pending work. Document unsupported downgrades and a recoverable reinstall/rollback procedure.
- [ ] Manual update delivery is acceptable initially if clear and verified. Begin provisioning alongside P03 rather than waiting for all runtime features to finish.
