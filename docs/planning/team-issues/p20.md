## What to build

Provide a first-run checklist, clear setup/recovery errors and an explicitly reviewed diagnostic export so founders can assist pilot teams without receiving their private code or secrets.

Type: **AFK**. Suggested work lane: **Desktop/product**. Parent user stories: 7, 30, 31.

## Acceptance criteria

- [ ] Guide account, endpoint enrollment, project/host pairing, provider readiness, first solo task and teammate invitation with actionable stage-specific failures.
- [ ] Diagnostics include only necessary versions, capability/error identifiers and redacted health state; exclude prompts, paths/repository names, diffs, tool content, keys and credentials.
- [ ] Users can inspect the export before sharing; the product does not automatically send it externally. Document privacy/metadata and recovery-loss boundaries plainly.
- [ ] Exercise successful onboarding plus representative unsupported-account, missing-runtime, failed-enrollment and recovery errors through installed and browser clients.
