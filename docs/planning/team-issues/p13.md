## What to build

A project member stores an issue or PR URL with a task and copies a private task link that opens the relevant context only for authorized enrolled recipients.

Type: **AFK**. Suggested work lane: **Desktop/product**. Parent user stories: 42, 43.

## Acceptance criteria

- [ ] Validate supported URL schemes and render links safely. Store the related-work URL encrypted and round-trip it across authorized clients.
- [ ] A private link routes to authentication, membership checks and endpoint verification; it never reveals task content to an unauthorized visitor.
- [ ] Adding an association does not read, comment on, or publish task content to the external issue tracker automatically.
- [ ] Allow adding/removing associations and navigating the task from the same link after reconnect; external tracker integration is not required.
