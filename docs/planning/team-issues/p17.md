## What to build

Closing the app window leaves its execution host alive in the tray/menu bar so an authorized browser participant can continue. Explicit quit communicates and applies the effect on running work.

Type: **AFK**. Suggested work lane: **Desktop/product**. Parent user stories: 21, 22, 23.

## Acceptance criteria

- [ ] Close and reopen the installed window while a real task runs; no duplicate runtime appears and the other client remains able to participate.
- [ ] Explicit quit warns if tasks are active, confirms the user's intent, shuts down managed processes and reports unavailable state to teammates.
- [ ] Test platform process cleanup and tray/menu-bar controls. Sleep or lost connectivity is not reported as a successfully completed or stopped task.
- [ ] Fresh app launch restores connection/setup state without automatically replaying an uncertain task or command.
